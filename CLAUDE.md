# Vault — Claude Instructions

This folder is a personal knowledge vault (PKMS), driven from the Aram
PWA. You are working inside it: every path is relative to this folder.

## Layout (PARA)

| Folder | Holds |
|---|---|
| `🏗️ projects/` | Efforts with a goal and an end. One note per project. |
| `🔎 areas/` | Ongoing responsibilities with no end date (health, home, finances). |
| `📚 resources/` | Reference material and topics of interest. |
| `📦 archives/` | Finished projects and inactive material. Move, never delete. |
| `⚙️ system/` | Templates, indexes, and notes about how this vault works. `assets/` holds every uploaded photo and file, named `YYYY-MM-DD <original name>`. |
| `🌐 site/` | What's published on the private, read-only site. Only what the user chose to share. |

## Rules

- Notes are Markdown. File names are human-readable titles, not slugs.
- When the user attaches a file, it is already saved in `⚙️ system/assets/`.
  Read it before answering about it. Leave it there and link to it from the
  note it belongs to — browsing the notes shows only the four PARA folders.
- Never delete a note. Archive it into `📦 archives/` instead.
- Prefer editing an existing note over creating a near-duplicate — search first.
